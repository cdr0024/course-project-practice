## GitHub Practice Reflection  

1.) The purpose of a github commit is to save changes made and create a version of the current work. This makes it easier to revert back to previous changes. It helps keep track of what changes were made when.  

2.) Git push moves any work committed locally to the Github. Git pull brings changes to the local workspace from the Github repository.  

3.) Branches allow the members of the development team to work on separate parts of a project without interfering with one another. It also allows for pull requests to the main project so that conflicts between different branches can be resolved before being moved into the main project.  

4.) I did not have much confusion with this Github practice assignment as I have used GitHub in my internships and within two different courses before this course.  

5.) I think Github will be very useful in helping our team manage the course project because it will allow us to keep track of everyone's changes and allow everyone to work on different parts of the project at the same time. It will also be useful to be able to revert back to previous versions of the project if needed.
